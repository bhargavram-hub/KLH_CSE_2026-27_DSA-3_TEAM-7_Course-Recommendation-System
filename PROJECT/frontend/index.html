Project map

A simple explanation you can use during the full project review.

01

Student gives requirements

Career goal, interests, completed courses and credit limit become the input.

02

Search finds relevant courses

KMP, Z-function and Rabin-Karp perform exact pattern matching. If the query has mistakes, edit distance provides fuzzy recovery.

03

Eligibility is checked

A prerequisite graph is traversed using DFS to find missing prerequisite courses.

04

Learning path is optimized

Recommendation scores are treated as values and credits as weights in 0/1 Knapsack DP.

05

CO4 allocation is demonstrated

Bipartite matching assigns students to eligible courses; Edmonds-Karp respects course capacity.

06

Advanced DSA is demonstrated

CO1–CO6 lab modules make the syllabus concepts executable instead of only theoretical.
